# nexuscontents-site

넥수스(NEXUS) 공식 홈페이지 — https://nexuscontents.com

서울의 피부과·에스테틱·메이크업숍과 한국을 찾는 일본·해외 크리에이터를 연결하는
마케팅 회사 넥수스의 소개 사이트입니다. 한국어 / 日本語 / English 3개 국어를 지원합니다.

## 구성

정적 사이트입니다. 빌드 과정이 없습니다.

```
index.html   사이트 전체 (HTML + CSS + JS 한 파일)
hero.jpg     첫 화면 배경 사진
CNAME        커스텀 도메인 설정 — 삭제 금지
.nojekyll    Jekyll 처리 비활성화 — 삭제 금지
```

## 로컬에서 보기

`index.html`을 브라우저로 열면 됩니다. 서버가 필요 없습니다.
(`hero.jpg`가 같은 폴더에 있어야 사진이 보입니다.)

## 배포

`main` 브랜치에 푸시하면 GitHub Pages가 1~2분 안에 자동으로 반영합니다.

## 수정하기 전에

**[AGENTS.md](./AGENTS.md)를 먼저 읽어 주세요.** 3개 국어 처리 방식, 되돌리면 안 되는
레이아웃 수정들, 문구 수정 규칙이 정리되어 있습니다.
